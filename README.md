# موقع أثر — النسخة الملكية الجديدة

موقع عربي RTL بهوية سوداء وذهبية، متجاوب مع الجوال، ويقرأ بيانات أحدث إصدار من `website-latest.json`.

## النشر على Vercel
1. ارفع محتويات هذا المجلد إلى مشروع Vercel الحالي أو انشر ZIP جديدًا.
2. تأكد أن `index.html` و`website-latest.json` في جذر الموقع المنشور.
3. اختبر رابط الموقع من الهاتف.

## تحديث APK لاحقًا
عند رفع APK جديد إلى Cloudflare R2، عدّل `website-latest.json` فقط ليشير إلى اسم الملف الصحيح ورقم الإصدار الصحيح، ثم انشر تحديث الموقع. مثال: 

```json
{
  "appName": "Athar",
  "versionName": "1.1.520",
  "versionCode": 11520,
  "apkUrl": "https://pub-4726b134fac64798a01dcee4782f9dcb.r2.dev/REPLACE-WITH-EXACT-APK-FILENAME.apk",
  "releaseNotes": ["تحسينات وإصلاحات"],
  "updatedAt": "YYYY-MM-DD"
}
```

**مهم:** اسم الملف في `apkUrl` يجب أن يطابق اسم APK الموجود فعلًا في R2. لا يمكن للموقع معرفة أحدث ملف تلقائيًا من رابط المجلد وحده. لا تغيّر إعدادات OTA داخل تطبيق أندرويد؛ هذا الملف خاص بزر تنزيل الموقع فقط.

## ملاحظات قبل الإطلاق
- البريد الإلكتروني غير مضبوط حتى الآن.
- صفحة الخصوصية مسودة تحتاج إلى مراجعة قانونية وتقنية تعكس سلوك التطبيق الفعلي.
- قسم «القادم في أثر» يعرض أفكارًا تطويرية بوضوح، ولا يدّعي أن كل ميزة تعمل في الإصدار الحالي.
- راجع `website-latest.json` بعد كل رفع APK.
